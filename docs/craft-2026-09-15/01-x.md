## 1. What the platform rewards now
- HARD (code). For You score = Σ weight × P(action); weights multiply *predicted probabilities*, not counts. param.rs, 2026-09-15: like 0.5, repost 1.0, reply 5.0, quote 5.0, share 2.0, DM share 5.0, copy-link share 20.0, follow-author 4.0, open link 0.2, click 0.4, photo expand 0.05, video open 0.07, dwell 0.05, profile click 0.0; not-interested −43.2, block −31.2, mute −58.8, report −234, not-dwelled −0.02. Reply and quote ≈ 10× a like, copy-link share 40×, one predicted report ≈ −470 likes.
- HARD. Replies on *original* posts from mutual follows get +15 reply weight. Same-author posts decay ×0.5 each, floor 0.25; out-of-network ×0.75; new authors get a boost; posts >48h leave the pool (Youngblood 2026-08-14).
- HARD. No scorer term for Premium, links, media, hashtags or language; they act via predicted engagement and filters. The 2023 verified multipliers (4× in-network, 2× out; Sprout 2026-02-06) are gone.
- CONFLICT. Buffer 2026-02-24 ("reply 27×, conversation 150×") and Sprout 2026-02-06 ("reply 13.5×, repost 20×") are 2023 README weights (reply 13.5, author-engaged reply 75). Use the 2026 file.
- Premium (Buffer 2025-10-02, 18.8M posts to Aug 2025): median impressions free <100, Premium ~600, Premium+ >1,550; median ER free 0% since Mar 2025 vs Basic 0.55%, Premium 0.49%, Premium+ 0.53%. Tier is the biggest reach lever.
- Links, sources disagree. (a) Buffer 2025-10-14: link posts 0% median ER free, ~0.28% Premium, vs text 0.40% / 0.90%. (b) Bier 2025-10-19: the browser covers the post, people forget to like; Musk: a good caption/image "will get distribution". (c) 2026-07-28, Bier: "you do not need to put the links in replies anymore"; Musk: "We haven't for over a year". Code has no penalty term (open-link +0.2); link clicks −28% in 2025 (Metricool 2026-02-26). Links still measure lowest.
- Format (Buffer 2026-03-05, ER = engagements ÷ reach): text 3.56%, image 3.40%, video 2.96%, link 2.25%; author replying to comments +8%. Dwell weights are tiny; don't pad.

## 2. Post anatomy
- HARD. 280 characters free, 25,000 Premium, threads ≤50 posts (Typefully 2026-07-21). URLs count 23, emoji 2, auto-populated reply @mentions 0 (docs.x.com).
- HARD (feed). Long posts collapse behind "Show more" after roughly 280 characters; the first 280 is the post.
- HEUR. Hook ≤ ~70 characters; quick-read posts 70–100 characters; the "<100 chars = +17%" figure is Buddy Media, ~2012 (via Hootsuite 2026-07-14): weak. One idea per line.
- Long post vs thread: 44.87 long posts vs 15.28 threads per account-week (Metricool 2024-10-16) is adoption, not performance. Threads 4–8 posts (Avenue Z 2026-04-20, HEUR); post 1 stands alone; one claim each; recap + CTA last.
- CTA last (last post in a thread), never the hook; any link rides with it (§5).

## 3. Formats ranked, and which funnel stage each serves
1. Text post: ER 3.56% (Buffer 2026-03-05). Attention, expertise.
2. Reply on a target account: weight 5.0, +15 with mutuals, Premium ranked first (Postory 2026-05-18). Attention.
3. Quote post: weight 5.0, equal to reply. Point of view, news reaction.
4. Thread or Premium long post: expertise, decide (worked case).
5. Image post: 3.40%, within 5% of text. Expertise (proof), decide (product).
6. Poll: no credible 2025–26 data. Attention only. HEUR.
7. Link post: lowest (2.25%; 0% free). Decide only.
- Type map: build in public → text/image; knowledge → thread/long post; point of view → text/quote; news reaction → quote; quote → text.

## 4. Hooks
HEUR; no large-sample hook study exists.
- Number + outcome: "We cut onboarding from 14 days to 3. One change did it."
- Defensible contrarian claim: "Most churn dashboards measure the wrong month."
- Concrete scene: "Third refund request this week. Same reason."
- Reads as AI or spam (fail): "Here's the thing", "Let that sink in", "Thread 🧵", "game-changer", rocket emoji, "Tag someone who…"; engagement bait ("like if", "RT to win"), a policy matter (HARD); curiosity gaps without payoff.
- First line: ≤70 characters; the claim, not the setup; a concrete noun; no @, #, link, emoji.

## 5. Writing rules
- Voice: the client's; verbs over adjectives; specifics over categories.
- No-AI-tells (Wikipedia 2026-08): no delve/underscore/tapestry/vibrant/game-changing/seamless; no "not just X, but Y"; no rule-of-three; ≤1 em dash; no bold; no closing summary; no "experts say".
- Hashtags: HARD, banned from ads since 2025-06-27 (Musk 2025-06-26). HEUR, 0–1 organic, never in the hook (Sprout 2025-11-06 and Buffer 2026-02-24: "1–2 max"). The "+21%/−17%" figures are 2012 Buddy Media.
- Mentions: only accounts discussed, ≤2, never first. Emoji 0–1, never bullets.
- Links: default none. If funnel = decide: one link, described in the caption (Musk 2025-10-19); first reply for non-Premium clients (Buffer 2025-10-14), in-post for Premium (Bier 2026-07-28).
- Numbers: each traces to a client document or openable URL; no rounding up.

## 6. Media rules
- Helps: a real screenshot, photo, before/after or data view adding a fact. Image 3.40% vs text 3.56% (Buffer 2026-03-05); Premium image 0.42% vs free 0.20% (Buffer 2025-10-14).
- Hurts: stock imagery, text-on-image restating the post, off-brand memes, link-preview cards (a link post).
- Client pictures (HARD specs): 16:9 at 1200×675, ≤5 MB, ≤4 per post (HeyOrca 2026-02-17); 16:9 renders uncropped; 2–4-image grids crop centre (2 images ≈ 7:8 each), so centre subjects (PostEverywhere 2026-03-25). One image; alt text; no logo-only images; must match the claim.

## 7. Distribution mechanics
- Windows disagree. Buffer 2026-03-13 (8.7M posts): Tue 9am, Wed 9–10am; worst 6–11pm and Saturday. Hootsuite 2025-11-19 (1M posts): Wed–Fri 9–11am. Sprout 2026-03-31 (~2B engagements): Tue–Thu 12–6pm; Saturday worst. Metricool 2024-10-16: Wednesday, peak hour 9pm. Consensus Tue–Thu; morning vs afternoon unresolved: default 9–11am local, then learn.
- Cadence: brand median 2.24 posts/week at 0.03% ER (Rival IQ 2026-03-05); average 17.34/week (Metricool 2026-02-26); largest accounts ~95/week (Metricool 2024-10-16); Buffer 2026-02-24: daily, up to 3–5×/day. Diversity decay rewards spacing; cadence 1–3/day.
- Replies: weight 5.0, +15 with mutuals; author replies +8% (Buffer 2026-03-05); answer within 2–3h (Sprout 2026-02-06); HEUR 5–10 substantive replies/day on target accounts, minutes after they post (Hermit 2026-07-22). Quote-comments (weight 5.0) add a position, never "This."
- First hour: no public data; HEUR, be present in hour one. Self-repost after ~24h (Hermit 2026-07-22, HEUR); duplicates are a policy risk.
- Founder vs company: no large-sample X study. Founders reply, earn mutual follows (+15) and follows (4.0); companies rarely do. Company: proof, product, news. Founder: build in public, point of view, replies.

## 9. What to measure and benchmarks
- Per follower (brands): 0.03% median (Rival IQ 2026-03-05; 150 companies × 18 industries); 0.10% average (Socialinsider 2026-01-16). By industry: sports 0.07%, higher ed 0.04%, finance 0.03%, tech/nonprofit/alcohol 0.02%, media/retail/travel 0.01%, fashion/food/beauty 0.00% (Rival IQ via Apaya 2026-07-16).
- Per impression: text 3.56% median (Buffer 2026-03-05); Premium text ~0.9% (Buffer 2025-10-02); 1.58% average (Metricool 2026-02-26). By account size (Metricool 2024-10-16): tiny 2.21%, small 1.3%, medium–huge ~1.8%.
- Impressions per post: median free <100, Premium ~600, Premium+ >1,550 (Buffer 2025-10-02); average 2,711 (Metricool 2026-02-26); brand average 2,979 (Socialinsider 2026-01-16).
- Per post (Metricool 2026-02-26): likes 32.89, reposts 6.67, replies 2.56, profile clicks 5.68; reply rate ≈ 0.09% of impressions; target ≥0.1%.
- Link CTR: no credible benchmark; link clicks −28% YoY (Metricool 2026-02-26). Log the client's own.

## 10. Pre-delivery checklist
1. ≤280 characters unless Premium client and type = knowledge; claim inside the first 280.
2. First line ≤70 characters, no @, #, link, emoji; one claim; ≤1 em dash; no AI-vocabulary; no rule-of-three.
3. Every number has an openable source.
4. Hashtags 0–1, none in hook; mentions ≤2, none first.
5. Link only if funnel = decide; one; per Premium flag; described in caption.
6. No engagement bait or giveaways.
7. Not a near-duplicate of the last 30 days.
8. Image: client-owned, 16:9, ≤5 MB, alt text, matches text.
9. Forbidden topics, regulated claims, competitors pass.
10. Type and funnel goal stated; CTA matches, sits last; threads ≤8 posts, each standing alone.
11. Slot Tue–Thu in client window; not Saturday.
12. One post, draft-only, paste-ready, no client-review narration.

## 11. Feedback for the developer integrating this
- Research: pull the client's last 30 posts and 3–5 target accounts' recent posts with reply counts; read Premium tier, timezone, cadence from the profile (tier is a hard input).
- Decide: by §3; default text; thread only for knowledge; quote for news reaction; link only if funnel = decide.
- Vet: §10 as pass/fail, quoting the failing line; block on 1, 3, 6, 9, 12; warn otherwise.
- Draft: 280/23/2 counting (docs.x.com); hook ≤70; ≤1 em dash.
- Non-overridable: character limits, platform-manipulation policy, forbidden topics, sourced numbers, draft-only, one post per run, no review narration. Client may override: hashtags, link placement, emoji, cadence, window, tone, thread length, image.
- Log per draft: type, funnel, length, hook pattern, media, link position, Premium tier, slot, client edit diff; per result at 1h/24h/48h: impressions, likes, replies, reposts, quotes, bookmarks, link clicks, profile clicks, follows. After 20 posts re-derive windows and formats, where public studies disagree.
