# `handoff/` — session carrier, not product code

This directory exists so a Claude Code session on one account can hand work to a session on another.
**It must never be merged into `main`.** Committed report files in the main tree are a standing sore
point with the team; if something here needs to reach `main`, extract the fix, not the paperwork.

Each subdirectory is one handoff. Start at its `CONTINUE-HERE.md`.
